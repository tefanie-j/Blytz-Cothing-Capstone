Help — Manual Editing

Selecting

Click an object on the shirt or select from the Layers panel on the right.

Moving

Drag any object freely across the canvas. Objects may extend beyond the shirt during editing — they will be clipped on the Review page.

Resizing

Drag any of the 8 handles around a selected object to resize it.

Rotating

Drag the white handle above a selected object, or use the Rotation slider in the properties panel.

Auto Layout

Click Auto Layout in the properties panel to position the selected object automatically, or use Auto Layout All in the toolbar.

Front / Back

Switch sides using the Front / Back buttons in the toolbar. Each side has its own objects.
