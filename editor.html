Help — Editor

Select V

Click to select. Drag to move, drag corner handles to resize, drag the top handle to rotate.

Draw D

Freehand drawing. Adjust brush size and color in the bar that appears at the top.

Eraser E

Click any element to remove it. Works on design objects and drawn paths.

Text T

Click on the canvas to place a text box. Double-click any existing text to edit it.

Image I

Opens a file picker to upload an image from your device.

Shapes S

Pick a shape from the fly-out, then click or drag on the canvas to place it.

Crop C

Select an image first, then click Crop. Drag the handles to define the visible area, then click Apply.

Front / Back

Switch sides using the buttons at the top. Each side has its own independent layers.

Shortcuts

Delete removes selected object · Ctrl+Z undo · Ctrl+Y redo · Ctrl+D duplicate · Esc cancel / deselect
